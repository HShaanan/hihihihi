# ספריא → NotebookLM: עיבוד וארגון הספרים התורניים

סקריפט Python (`process_sefaria.py`) שמחלץ את כל הטקסטים העבריים של [Sefaria-Export](https://github.com/Sefaria/Sefaria-Export),
מנקה אותם מתגיות HTML ומטא-דאטה, ומאגד אותם לקבצי TXT (UTF-8) מרוכזים עם כותרות Markdown,
במבנה שמתאים להעלאה ישירה ל-NotebookLM (מגבלת 50 מקורות למחברת) ולגיבוי בגוגל דרייב.

## רקע חשוב: איפה הטקסטים יושבים

מאגר ה-GitHub של Sefaria-Export **כבר לא מכיל את הטקסטים עצמם**. מאז ספטמבר 2026 הוא מכיל רק
אינדקס (`books.json`, ~21MB) וכלי עזר. הטקסטים (~26GB, ~85K קבצים) יושבים בדלי GCS ציבורי:

```
https://storage.googleapis.com/sefaria-export/json/{categories}/{title}/{language}/merged.json
https://storage.googleapis.com/sefaria-export/schemas/{Title_With_Underscores}.json
```

לכן הסקריפט קורא את `books.json` מהשיבוט המקומי, מסנן את 6,214 קבצי העברית הממוזגים
(`language == Hebrew`, `versionTitle == merged`), ומוריד אותם (עם קבצי הסכמה) ישירות מהדלי, במקביל ועם מטמון.

## הרצה

```bash
git clone https://github.com/Sefaria/Sefaria-Export.git          # ~25MB, רק האינדקס
python3 process_sefaria.py --repo ./Sefaria-Export --out ./sefaria_notebooklm_export --cache ./sefaria_cache
```

אפשרויות: `--workers N` (ברירת מחדל 24), `--max-mb N` (גודל מרבי לקובץ, ברירת מחדל 45),
`--only 01,03` (רק תיקיות מסוימות), `--limit N` (לבדיקה מהירה).
ההרצה המלאה מורידה כ-2.8GB JSON ומייצרת כ-2.0GB טקסט נקי. אין תלויות מעבר לספרייה הסטנדרטית של Python 3.10+.

## מה הסקריפט עושה

1. **הורדה** – `merged.json` + סכמה לכל ספר, 24–32 הורדות במקביל, ניסיונות חוזרים, מטמון מקומי.
2. **ניקוי** – הסרת כל תגיות ה-HTML (`<b>`, `<i>`, `<small>`, `<br>`, `<span>`, `<sup>`, `<big>`, תגיות מפרשים
   `<i data-commentator=...>`), המרת `<br>` לשורה חדשה, הערות שוליים → `(הערה: ...)`, פענוח ישויות HTML,
   נרמול רווחים. מטא-דאטה של JSON (`versions`, `versionSource`, מפתחות מערכת) לא נכתבת לפלט.
3. **מבנה פנימי (Markdown)** – לכל ספר:
   ```
   # בראשית
   (ספריא: Genesis | קטגוריה: תנ"ך / תורה)

   ## פרק א
   פסוק א: בְּרֵאשִׁ֖ית בָּרָ֣א אֱלֹהִ֑ים ...
   ```
   שמות הרמות נלקחים מהסכמה של ספריא בעברית (`heSectionNames`): פרק/פסוק, פרק/משנה, פרק/הלכה,
   סימן/סעיף, דף/שורה (דפי גמרא בסימון `דף ב.` / `דף ב:`), ולטקסטים מורכבים (זוהר, טור, הגדה) –
   כותרות לפי צמתי הסכמה (`## אורח חיים` → `### הקדמה` ...). המספור באותיות עבריות (א, ב, ... טו, טז ...).
4. **איגוד** – הספרים משויכים לתיקיות ולכרכים לפי החלוקה התורנית של ספריא, ממוינים לפי תוכן העניינים
   של ספריא, ונכתבים לקובץ TXT אחד לכל כרך. כרך שעובר 45MB מפוצל אוטומטית ל`_חלק_א`, `_חלק_ב` ...
   (תמיד בגבול ספר, ולעולם לא מעל 50MB).
5. **סיכום** – בסיום מודפסת טבלה: מספר קבצים, ספרים וגודל לכל תיקייה, ומיקום תיקיית הפלט.

שתי התיקיות האחרונות (`10`, `11`) נוספו מעבר לתשע שברשימה המקורית: ספרות השו"ת (כ-235MB JSON) לא
הייתה נכנסת לתיקיית ההלכה בלי לחרוג בהרבה מ-15 קבצים, וסידור/הגדה/ספרות בית שני/ספרי יעץ אינם שייכים
לאף אחת מהתשע. כל תיקייה נכנסת בנפרד למחברת NotebookLM אחת (עד 50 מקורות).

## ניקוי – לפני ואחרי

לפני (`Shulchan Arukh, Orach Chayim 1:1` ב-JSON):
```
<b>דין השכמת הבוקר. ובו ט סעיפים:</b><br><i data-commentator="Be'er HaGolah" data-label="א" data-order="1"></i>יתגבר <i data-commentator="Ba'er Hetev" data-order="1"></i>כארי לעמוד בבוקר ...
```
אחרי:
```
## סימן א
סעיף א:
דין השכמת הבוקר. ובו ט סעיפים:
יתגבר כארי לעמוד בבוקר לעבודת בוראו שיהא הוא מעורר השחר: הגה ועכ"פ לא יאחר זמן התפלה ...
```
